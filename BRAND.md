# ReelStudy brand

Open Reel is ReelStudy's canonical logo. The open book carries the study product; the vertical reel carries the swipe-through learning model.

## Production files

| File | Use |
| --- | --- |
| `web/public/brand/open-reel-mark.svg` | Full-color mark on light backgrounds |
| `web/public/brand/open-reel-mark-reversed.svg` | Mark on the ink background |
| `web/public/brand/open-reel-mark-one-color.svg` | Single-color printing and stamps |
| `web/public/brand/open-reel-lockup.svg` | Outlined horizontal logo for handoff or print |
| `web/public/brand/open-reel-icon-*.png` | App and browser icon sizes |
| `web/public/brand/favicon.ico` | Multi-size browser favicon |

## Palette

| Token | Hex | Role |
| --- | --- | --- |
| Ink | `#20242C` | Reel, outlines, dark surfaces |
| Page yellow | `#FFD65A` | Left page and focus accent |
| Reel orange | `#FA541C` | Right page and wordmark accent |
| Paper | `#FFFDF8` | Light seam and reversed detail |
| Accessible orange | `#C93C09` | Buttons carrying white text |

## Usage

- Keep clear space around the mark equal to the center gutter's width.
- Use the mark alone down to 16px. Use the lockup only when the wordmark remains comfortably readable.
- Use the full-color mark on white or paper, the reversed mark on ink, and the one-color mark when color is unavailable.
- Set the live wordmark in Gabarito at weight 800. The handoff lockup is outlined and has no font dependency.

## Do not

- Reintroduce the rejected sun, mascot, pointing hand, or book-stack concepts.
- Add gradients, shadows, extra symbols, or an AI sparkle.
- Stretch, rotate, or recolor individual pages.
- Put the full-color mark directly on orange or yellow.
